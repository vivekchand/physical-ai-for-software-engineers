# Instructions for contributors and coding agents

This is an independent educational repository, not the ClawMetry product repository.
Never copy credentials, private project files, commercial plans, or user data here.

Keep lessons original and grounded in primary references. Prefer concise theory,
one practical experiment, a checkpoint, and an explicit artifact for each day.
Use a dated compatibility snapshot for NVIDIA/ROS instructions. Never describe
documentation review or CPU tests as proof that GPU or hardware workflows ran.

Edit Markdown sources and the static generator, not `dist/`. No backend, analytics,
accounts, or remote JavaScript is required. Keep progress local to the browser.
Site code and portable examples are MIT; prose is CC BY 4.0. External work retains
its own license. Do not reproduce external textbook passages, figures, or videos.

Use branches and pull requests for changes after initial repository creation.
Run the CONTRIBUTING.md checks, and preview UI changes at desktop and mobile sizes.
